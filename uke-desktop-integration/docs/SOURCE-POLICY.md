# Source and publication policy

Pin source revisions, licenses and file hashes before introducing payloads.
OEM/community inventory describes hypotheses; physical behavior needs its own
record. Never copy Nabu offsets, security firmware, calibration or driver wiring.
Record host-only upstream build exceptions with exact package/tool pins.
No project Python program or runtime ships in this package. The 14 October
2026 exception permits unmodified Fedora desktop dependencies to retain their
distribution Python components; it does not permit a project Python service.

Project-original documentation and scaffold files use the MIT license. Imported
source keeps its upstream license and attribution; firmware licenses are
file-specific and are never inferred from this repository license.
