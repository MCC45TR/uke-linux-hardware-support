# Uke Control Qt 1.7.1 source recipe

This spec matches the signed Fedora Rawhide AArch64 source RPM. It pins the
Control client SDK used in the build. Verify the source RPM against
`source-rpm.sha256` and the Uke Unstable repository signing key before
extracting the build inputs.

[Signed source and runtime build](https://copr.fedorainfracloud.org/coprs/build/11403291/)
