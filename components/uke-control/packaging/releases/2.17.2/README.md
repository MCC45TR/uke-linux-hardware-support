# Uke Control 2.17.2 source recipe

This spec matches the signed Fedora Rawhide AArch64 source RPM. It records
all cumulative patches, source pins and the feature ownership of the single
Uke Control package. The complete input set is in that source RPM. Verify the
source RPM against `source-rpm.sha256` and the Uke Unstable repository signing
key before extraction.
