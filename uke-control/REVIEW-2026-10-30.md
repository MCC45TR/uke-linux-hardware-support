# Expanded review implementation decisions

30 October 2026. Baseline: hardware-support commit
`6fd84c6331e1a9d7aaaadd67db21b7f0b933b036`. This source change evaluates
all 33 findings, eight optimizations and eighteen proposed features in the
expanded review. Changes target Control 2.4.0, applet revision 24 and KCM 0.2.0.
The review report is an input assessment, not physical failure evidence.

“Implemented” below describes source behavior. Fixtures, builds, package contents,
installed lifecycle and physical acceptance remain distinct. No new electrical
limits, partition geometry or donor calibration values were introduced.

## Source and release gates

CI has independent contracts, native, bus, signed-repository and interface jobs.
All matrix suites must succeed before the separate COPR request job can run.
A skipped/failed suite is not success. COPR must also have the exact validated
SCM checkout; posting arbitrary JSON does not pin a normal SCM source.

KScreen adapter evidence: upstream
[serializer](https://github.com/KDE/libkscreen/blob/master/src/configserializer.cpp)
blob `54a088199342220d450f739b9b6e057deabbe772` and
[output enums](https://github.com/KDE/libkscreen/blob/master/src/output.h)
blob `f3fe7e33ab59ad70ec776d269f3481fea342fd85`, inspected 30 October 2026.
KCM loading and translation use the original KDE KCMUtils/KI18n APIs. No KDE
application was forked. No new Python target dependency was introduced.

Publish only after source/RPM payload checks, then perform separately recorded
installed upgrade/removal, active-session authorization, interrupted boot/storage,
USB/accessory, charging, rendering and physical acceptance. Source fixture success
cannot close an FMEA/8D effectiveness gate. Central engineering findings belong
in uke-linux-docs; executable contracts and these decisions stay with this source.
